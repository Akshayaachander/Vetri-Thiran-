# 8. Project Demonstration Phase

## Project Title

EduGenie – Google Gemini Powered Learning Assistant

## 1. Introduction

The Project Demonstration Phase presents the completed EduGenie application and demonstrates its main features and functionality.

EduGenie is an AI-powered learning assistant designed to help students understand topics, summarize content, practice questions, generate quizzes, and follow personalized learning paths.

## 2. Demonstration Objectives

The demonstration aims to show:

- The EduGenie user interface.
- How users enter learning topics.
- How AI-generated explanations are provided.
- How educational content is summarized.
- How quizzes are generated.
- How practice questions are generated.
- How learning paths are created.

## 3. Features Demonstrated

### 3.1 AI Explanation

A topic is entered into the application and the Explain feature is selected.

EduGenie uses Google Gemini to generate a simple and understandable explanation.

### 3.2 Summarization

Educational content is entered and the Summarize feature is selected.

The system generates a concise summary containing important information.

### 3.3 Quiz Generation

A topic is entered and the Quiz feature is selected.

The system generates multiple-choice questions with options, answers, and explanations.

### 3.4 Question Generation

The Questions feature generates practice questions based on the selected topic.

The generated questions include answers and difficulty levels.

### 3.5 Learning Path

The Learning Path feature creates a structured sequence of learning steps.

This helps students learn a topic in a systematic way.

## 4. Demonstration Flow

The demonstration follows these steps:

1. Start the EduGenie FastAPI server.
2. Open the EduGenie application in a web browser.
3. Enter an educational topic.
4. Select the Explain feature.
5. Demonstrate the generated explanation.
6. Select the Summarize feature.
7. Demonstrate the generated summary.
8. Select the Quiz feature.
9. Demonstrate the generated quiz.
10. Select the Questions feature.
11. Demonstrate the generated practice questions.
12. Select the Learning Path feature.
13. Demonstrate the generated learning steps.

The demonstration shows that EduGenie provides multiple AI-powered educational features through a single web application.
