# 2. Requirement Analysis Phase

## Project Title
EduGenie – Google Gemini Powered Learning Assistant

## 1. Introduction

The Requirement Analysis Phase identifies the functional and non-functional requirements needed to develop the EduGenie AI-powered learning assistant.

## 2. Problem Statement

Students may find it difficult to understand complex topics, summarize lengthy study materials, prepare questions, and practice through quizzes. EduGenie is proposed to provide AI-based learning support in one platform.

## 3. Functional Requirements

The system should:

- Allow users to enter a topic or learning content.
- Generate simple explanations for topics.
- Summarize educational content.
- Generate quizzes based on topics.
- Generate questions and answers.
- Create personalized learning paths.
- Provide AI-powered learning assistance.
- Display generated content in a clear and readable format.

## 4. Non-Functional Requirements

- The application should be user-friendly.
- The system should provide accurate and useful responses.
- The application should respond within a reasonable time.
- The system should be reliable and easy to maintain.
- API keys and sensitive information should be kept secure.
- The application should work properly on modern web browsers.

## 5. Hardware Requirements

- Laptop or computer
- Minimum 4 GB RAM
- Internet connection
- Keyboard and mouse

## 6. Software Requirements

- Python
- FastAPI
- HTML
- CSS
- JavaScript
- Google Gemini API
- Visual Studio Code
- Modern web browser

## 7. Target Users

The main target users are:

- School students
- College students
- Students preparing for examinations
- Self-learners

## 8. Main Modules

The proposed system contains the following modules:

1. Explanation Module
2. Summarization Module
3. Quiz Module
4. Question Generation Module
5. Learning Path Module
6. AI Learning Assistant Module

## 9. Expected Outcome

EduGenie should provide students with an easy-to-use AI learning platform that supports understanding, revision, practice, and personalized learning.

## 10. Conclusion

The Requirement Analysis Phase defines the major requirements, users, software, hardware, and modules needed for developing EduGenie.
